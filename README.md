# مملكة الشفاء — Kingdom of Healing

واجهة React + Vite عربية باتجاه RTL، معدّلة لتقترب بصريًا من مرجع التصميم المرفق، مع استخدام صور واقعية للواجهة الطبية وصورة المركز وشعار العلامة التجارية.

## التشغيل

1. فك ضغط المشروع.
2. افتح مجلد `kingdom-of-healing` في VS Code.
3. افتح Terminal داخل المجلد وشغّل:

```bash
npm install
npm run dev
```

لفحص بناء نسخة الإنتاج:

```bash
npm run build
```

## الصور

الصور المستخدمة موجودة داخل `public/images` ويتم تحميلها محليًا بواسطة الموقع؛ لا يحتاج الموقع إلى روابط صور خارجية. صور الأطباء المستخدمة في البطاقات مقتطعة من صور الهوية البصرية المرفقة لأغراض النموذج التجريبي.

## تنبيه

هذا نموذج واجهة أمامية للعرض فقط. البيانات تجريبية ولا توجد قاعدة بيانات أو مصادقة خلفية حقيقية. لا تستخدمه لتخزين بيانات مرضى حقيقية.
